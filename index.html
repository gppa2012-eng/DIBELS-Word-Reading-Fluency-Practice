Practice Activity

Scoring Word Reading Fluency

DIBELS 8th Edition WRF Benchmark 2.Middle

Examiner script "Please read from this list of words (point to the student form). Start here (point to the first word) and go across the page (point across the page). When I say 'Begin', point to each word and read it the best you can. If you get stuck, I will tell you the word, so you can keep reading. Put your finger on the first word. Ready? Begin."
Reminders Start timer: when the student says the first word.
Prompts: if the student hesitates, wait 3 seconds, give the correct word, point to the next word and say "Keep going," and mark the missed word as incorrect.
Discontinue: if the student does not get any words correct within the first line (5 words), discontinue WRF.

Score the passage

As the student reads, click a word to slash it as an error. Use the bracket tool to mark the last word read when the timer ends. Self-corrections are not errors. The number at the end of each row is the running word count.
